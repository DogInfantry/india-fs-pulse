## What it was built to answer

India built the world's largest real-time payments network and charges nothing to use
the half of it that could be charged for. Who captures the value instead, and is there
an investable business model in the answer?

## Visualisation and design tooling evaluated

Every one of these was evaluated. Recording the **rejections** matters as much as the
adoption: choosing a tool is only half a sourcing decision, and a tool nobody ruled out
is a tool nobody actually chose.

| Resource | Link | Verdict |
|---|---|---|
| **Perspective** | https://github.com/perspective-dev/perspective | **Rejected for this site.** Genuinely excellent for large or streaming datasets; ships multiple megabytes of WASM to pivot 36 rows. The workbench is ~40 lines of DOM code instead, which is why Lighthouse stays at 100 |
| **Apache Superset** | https://github.com/apache/superset | Rejected: needs a live Python backend and a database; incompatible with static, free hosting |
| **Panel (HoloViz)** | https://github.com/holoviz/panel | Rejected: same backend constraint. Pyodide export exists but would ship a Python runtime to draw a bar chart |
| **Vizro (McKinsey)** | https://github.com/mckinsey/vizro | Rejected: Dash/Flask server required. Worth revisiting if this ever gets a backend |
| **Redash** | https://github.com/getredash/redash | Rejected: a hosted BI service, not a component; wrong shape for a portfolio artefact |
| **glue** | https://github.com/glue-viz/glue | Rejected: desktop linked-view exploration, not web publishing |
| **21st.dev** | https://21st.dev | Referenced for UI component and layout craft |
| **impeccable.style** | https://impeccable.style | Referenced for finish and typographic restraint (the local `impeccable` skill covers the same ground) |
| **awesome-design** | https://github.com/gztchan/awesome-design | Referenced as a design-resource index |
| **gitdesign.md** | design-notes convention | Referenced; this file and `docs/stack-decisions.md` play that role here |
| **WebGPU** | https://www.w3.org/TR/webgpu/ | Rejected: no dataset here is within three orders of magnitude of needing GPU compute |
| **Flourish** | https://flourish.studio | Rejected: embeds are hosted iframes, so every exhibit would add a third-party origin, third-party JavaScript and third-party analytics to a page that currently loads nothing external. It would cost the CSP, the Lighthouse score and the privacy posture at once |
| **Flaticon, Freepik, IconScout** | flaticon.com, freepik.com, iconscout.com | Not adopted. Free tiers require visible attribution, and an answer-first analytical report has no place to put it that is not noise. Company marks come from Simple Icons instead, which is CC0 |
| **unDraw, Storyset** | undraw.co, storyset.com | Not adopted. Spot illustration would dilute a visual language that is currently exhibits only: every graphic on the page encodes a number. Recorded because the licences differ and it matters: unDraw needs no attribution, Storyset does |
| **Pexels** | https://pexels.com | Not adopted. There is no photograph that a chart of merchant share would be improved by sitting next to |
| **imagecolorpicker.com** | https://imagecolorpicker.com | A human tool with no repository footprint. The palette here is measured against WCAG contrast ratios rather than sampled by eye, which is the point of the `--signal` and `--signal-text` split |

**What was adopted instead:** Astro 5 (static), hand-written CSS, ECharts (lazily imported,
so the entry script is ~1.6 kB), and five hand-written server-rendered SVG components, `Marimekko`, `Waterfall`, `Slopegraph`, `SmallMultiples`, `SlopeLines`, which carry the
consulting chart vocabulary with zero client JavaScript.

### Rejected data sources, with the evidence

Recording a rejection matters as much as recording an adoption. A probe that came
back empty is evidence about the source, and discarding it means the next person pays
the same cost to learn the same thing.

| Source | Probed | Verdict |
|---|---|---|
| **RBI DBIE** | not probed | Angular application, no public REST API. **Worked around, not abandoned:** RBI's call money series is available through FRED (above), so the rate data is in the pipeline after all. NIM is still derived from filed statements |
| **data.gov.in** | Probed with a real key, held locally and never committed. `/catalog` 404s; `/lists` works and returns 8,256 resources. Pulled all 8,500 rows, keyword-matched 132 against UPI / bank / insurance / payment / NBFC | **Rejected.** Effectively everything relevant is a 2013–2018 snapshot: PMJDY to Mar-2016, card PoS transactions 2017, priority-sector lending 2014. Nothing current, nothing both state-level and recent |
| **Alpha Vantage** | Probed with a real key, held locally and never committed. `GLOBAL_QUOTE` for `HDFCBANK.BSE` returned live data | **Rejected.** Free tier rate-limits from the second call in a session (`OVERVIEW` and `FX_MONTHLY` both returned the throttle notice immediately), and it duplicates yfinance, which is already wired and unmetered. A key-gated source would also need to skip gracefully under rule 5 |
| **NPCI (direct)** | not probed | HTTP 403 to every scripted request. Transcribed by hand instead; see `docs/REFRESH.md` |

**One fetched series is deliberately unused.** `gdp_current_usd` is in
`worldbank_india` and nothing reads it. The obvious exhibit, UPI value as a share of GDP,
needs an INR to USD rate for the matching period, and no FX series is in this pipeline.
Picking a rate would be inventing a number, so the column stays fetched, documented and
unplotted until an FX source earns its place. `npl_pct_gross_loans`,
`domestic_credit_private_pct_gdp` and `account_ownership_female_pct` were in the same
state and are now used, in sub-modules B and C.

**Keys held but unused:** data.gov.in, Alpha Vantage and FRED. None is committed here,
not even as a fragment. FRED's key works, but the keyless CSV endpoint serves the same
series, so the pipeline does not use it. Rule 5 says `python run.py data` must run with zero
environment variables, and it still does.

## How to refresh the browser-only sources

`docs/REFRESH.md` has the full procedure. The short version: NPCI blocks scripted access,
so those two tables are read in a browser and transcribed into
`data-pipeline/data/manual/` with a per-row `source_url` and `accessed` date.

Three traps documented there, all of which caused real bugs:

1. NPCI renders only **10 rows per table with no pagination**.
2. Before ~2024 those ten rows are **alphabetical, not ranked**, so PhonePe is absent
   from December 2022, which is why the per-app series starts 2023-12.
3. A `#` in an app name is NPCI's **third-party-provider marker, not a comment**:
   parsing with pandas' `comment='#'` silently truncates every row to `NaN`.
